Autonomous Pretraining Research Swarm

One day, frontier AI research used to be done by meat computers in between eating, sleeping, having other fun, and synchronizing once in a while using sound wave interconnect in the ritual of "group meeting". That era is long gone. Research is now entirely the domain of autonomous swarms of AI agents running across compute cluster megastructures in the skies.

— Andrej Karpathy, March 2026

Give an AI agent a small but real LLM training setup and let it experiment autonomously overnight. It modifies the code, trains for 5 minutes, checks if the result improved, keeps or discards, and repeats. You wake up in the morning to a log of experiments and a better model.

How It Works

The repo has three files that matter. You write the research program in Markdown, the AI agent iterates on the training code, and the infrastructure stays fixed.

  • train.py Model, optimizer, training loop — the agent modifies this
  • program.md Agent instructions — the human modifies this
  • prepare.py Data prep & runtime utilities — fixed, not modified

Quick Start

# Install uv project manager
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install dependencies
uv sync

# Download data and train tokenizer (one-time, ~2 min)
uv run prepare.py

# Run a single training experiment (~5 min)
uv run train.py

Then spin up your AI agent, point it at program.md, and let it run autonomously.
